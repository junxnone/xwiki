# RDP 远程不能复制粘体文件文本

1. 打开任务管理器(快捷键 Ctrl+Shift+Esc ) → 详细信息
2. 找到 rdpclip.exe（RDP 剪贴板监视程序），右键结束任务
3. 任务管理器右上角「运行新任务」，输入 rdpclip.exe 确定
